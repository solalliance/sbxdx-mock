# SBxDX モック

[モックを開く](https://solalliance.github.io/sbxdx-mock/)

[画面付き操作説明書（PDF）](https://solalliance.github.io/sbxdx-mock/manual.pdf)

管理者・作業者・クライアントの画面を切り替えて確認できます。画面の会社・人物・期限などはサンプルです。操作内容はブラウザ内に保存されます。外部接続・実送信・本番認証は行いません。

## 管理の流れ

営業から問い合わせ・面談・見積・契約・受注を管理し、失注は見込みに残します。見込み一覧・連絡センターから定期メールの周期と予約を確認できます。

「請求・入金・連携」で請求、入金明細と未収額、入金後の連携先・処理結果・再試行を管理できます。全額入金を確認するまで外部連携を開始できません。実際のメール送信・外部API接続・自動入金消込は行いません。

管理者・作業者のホームにも営業・見込みフォロー・請求・未収・連携を表示し、カードから対象記録を確認できます。管理者は全体、作業者は担当範囲を集計します。

サービス設定に必要な作業・順序・条件を表示し、クライアントの案件では全作業と実担当を確認できます。未作成・未担当・対応可能者なし・担当見直しを区別し、既存案件の不足は明示操作で補完します。必要作業が不足・未完了の場合は案件完了を止めます。

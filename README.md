# SBxDX 初期運用モック

[モックを開く](https://solalliance.github.io/sbxdx-mock/)

2026-11-07：パート4名＋管理者の初期運用に整理しました。管理者・パート・クライアントを上部で切り替えられます。会社・人物・期限・回収状況はサンプルです。

## 業務の流れ

1. 見込み客・営業で問い合わせ、面談、見積、契約、受注を管理。
2. 受注サービスと対象期、窓口担当、期限を保存。
3. 顧客ごとに定款・謄本、電子申告情報、前期申告書、届出、会計ソフトの状況を確認。
4. 対象タスクの担当を設定して業務開始。資料と前工程が揃ったタスクから実行。
5. 休暇・退職時は未完了タスクを引き継ぎ、完了済みの担当履歴は保持。

新規顧客登録の共通準備8タスクを反映しています。決算・年末調整・届出・中間納付・源泉所得税などのサービスは維持し、サービス固有の資料とタスクは追加資料待ちと表示しています。共通準備完了をサービス全体の完了にはしません。

失注・保留とフォロー配信、請求・一部/全額入金、全額入金後の連携、顧客別TaxSys入口は継続します。操作はブラウザ内に保存され、実メール・外部API・本番認証は行いません。

組織拡張版はGitの `5c62d6c` に保持しています。開発側には旧HTMLと編集元の保管コピーもあります。

[以前の構成の画面付き説明書](https://solalliance.github.io/sbxdx-mock/manual.pdf) は旧版資料です。現在の初期運用画面とは構成が異なります。
